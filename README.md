# Home Calisthenics – תוכנית אימון

אפליקציית ליווי לאימון כוח ביתי: דמות מאוירת שמדגימה כל תרגיל, טיימר, ספירת חזרות ומנוחות, מהחימום ועד המתיחות.
ניתנת להתקנה למסך הבית ועובדת גם בלי אינטרנט.

## הרצה מקומית
```
npm start
```
ואז לפתוח http://localhost:3000

## פריסה ב-Railway
New Project → Deploy from GitHub repo → בחירת המאגר.
אחרי הפריסה: Settings → Networking → Generate Domain.
